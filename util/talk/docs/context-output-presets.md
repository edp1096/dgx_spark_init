# 문맥 크기별 출력 프리셋

설정 > 대화 > 지능형 문맥 관리에서 출력 프리셋을 선택한다. 항목은 넓은 화면에서 두 열, 700px 이하 화면에서 한 열로 표시한다.

| 문맥 크기 | 자동 최대 출력 |
| --- | ---: |
| 32K 이상 | 8,192 |
| 64K 이상 | 16,384 |
| 128K 이상 | 32,768 |
| 256K 이상 (512K·1M 포함) | 65,536 |

`자동`은 요청 시 현재 문맥 한도를 기준으로 계산하며, 문맥 한도가 0이면 서버에서 감지한 값을 사용한다. 감지 실패 시 저장된 `output_reserve`로 돌아간다. 32K 미만은 안전 여유를 뺀 문맥의 1/4을 사용하며, 안전 여유가 비정상적으로 큰 경우에도 예산을 줄인다. 추론 토큰과 최종 답변이 출력 한도를 함께 사용한다.

고정 프리셋은 `output_reserve`만 설정하며 직접 수정할 수 있다. 프리셋으로 모델 서버의 문맥 용량이 늘어나지는 않는다. 모델을 바꿔도 출력 예산을 맞추려면 `자동`을 사용한다. 수동 문맥 한도 자체는 서버 지원 범위 내에서 지정해야 한다.

설정 키 `context.output_auto`가 없는 기존 설정은 수동 값을 보존한다. 자동 모드에서도 수동 값을 보관하며, 실제 API의 `max_completion_tokens`와 입력 예산에서 차감하는 출력 토큰은 동일한 계산을 사용한다. 별도의 요약 요청 한도는 유지한다.

검증: 설정 프리셋 저장·복원 및 반응형 배치 브라우저 테스트, 1M→32K 전환의 API 출력 한도와 입력 예산 일치 통합 테스트.
