# 브라우저 제어

사용자 Chrome의 확장과 Talk를 연결해 로그인 상태를 그대로 사용한다. 확장 1.0.0 / 연결 프로토콜 14부터 범용 도구 `browser`와 네이버 전용 도구 `browser_reviews`가 같은 실행부를 사용한다.

## 사용

1. Talk 설정 → 기능 → 브라우저에서 확장 ZIP을 받아 기존 확장 폴더에 덮어쓰고 Chrome 확장 관리에서 새로고침한다. 기존 연결 키는 유지된다.
2. 다른 사이트를 제어하려면 확장 팝업의 **사이트 관리**에서 별도 설정 탭을 열고 **사이트 추가 → 허용**을 누른다. 서버 주소의 연결 권한과 작업할 사이트의 권한은 별개다.
3. Talk에서 작업을 요청한다. 모델은 `tabs → attach → observe → 조작 → observe` 순서로 현재 요소를 확인한다. `open`으로 새 탭도 만들 수 있다.
4. `release`는 탭 하나, `stop`은 해당 대화의 모든 탭 소유권을 반환한다. 탭은 닫지 않는다. 대화 삭제 등으로 소유권이 남으면 확장의 **작업 중지·탭 연결 해제**로 전체 작업을 취소하고 반환할 수 있다. `close`는 입력 변경이 없는 탭을 명시적으로 닫는다.

확장 1.0.2부터 네이버를 포함한 모든 사이트 권한은 선택 사항이며 목록에서 해제할 수 있다. 네이버 리뷰에는 실제 작업 탭의 주소(예: `https://shopping.naver.com`)를 허용한다. 권한 해제 시 진행 중 명령을 취소하고 초기 리뷰 보조 스크립트도 해제한다.

기존 네이버 사용 방법은 [구매후기](browser-reviews.md)를 참고한다. 리뷰의 상품 확인·사용자 수정 보존·등록 결과 확인과 중복 등록 방지는 네이버 어댑터가 담당한다.

## 구조

- `service-worker.js`: 연결, 연결을 넘나드는 단일 대기열, 명령 취소·만료, 결과 상태.
- `browser-sessions.js`: 서버가 지정한 대화별 세션과 탭 소유권. 소유권은 `chrome.storage.session`에 보관하고, 문서 참조와 파서 캐시는 재시작 후 다시 관찰한다.
- `browser-driver.js`, `dom-core.js`: 공통 Chrome 입력·좌표·포커스·선택·스크롤·탭 실행.
- `browser-tools.js`, `browser-content.js`: 범용 관찰과 요소 참조. 문서·탭·프레임·대화가 맞는 실제 요소만 조작한다.
- `naver-adapter.js`, `naver-content.js`: 네이버 상품·리뷰·질문 해석과 등록 검증. 별도의 직접 DOM 클릭/리뷰 작성 실행 경로는 제거했다.
- 서버 `browser_generic.go`: 대화 세션을 강제로 지정하여 호출하고 스크린샷을 첨부 이미지로 모델에 전달한다.

`effect_state`는 `none`(변경 입력 미실행), `committed`(요청한 조작 완료), `unknown`(실행했을 수 있으나 결과 불명)이다. 클릭 완료는 사이트의 등록·구매 성공을 의미하지 않는다. 연결이 끊긴 변경 작업은 재실행하지 않고 새 관찰로 확인한다.

## 범위와 검증

현재 한 브라우저 연결을 지원하며, 여러 대화가 같은 탭을 동시에 소유하지 못한다. 브라우저 팝업은 `tabs`의 창·opener 정보로 확인하고 `attach`로 지정한다. 네이버는 기존 상품 확인 절차로 팝업을 연결한다. 기존 탭을 임의로 전용 창에 옮기거나 자동으로 닫지 않는다.

범용 관찰은 프레임별 텍스트와 최대 300개의 DOM 요소를 반환한다. iframe 좌표를 확인할 수 없거나 가려졌으면 중단한다. 회전된 iframe, 닫힌 Shadow DOM, canvas 내부 요소, 파일 전송, 자격증명 관리, 다중 기기 관리는 이 구현의 범위 밖이다. 접근 권한이 없는 프레임의 내용은 읽지 않는다. `navigate/reload/close`는 모든 프레임의 변경 여부를 확인할 수 있어야 한다.

```sh
TALK_BROWSER_E2E=1 go test ./internal/browserbridge -count=1 -v
```

로컬 Chrome 재현 페이지로 네이버 입력·팝업·등록 확인과 범용 조작·요소 변경·대화 충돌·취소·재연결을 검사한다. 실제 네이버 리뷰 등록은 별도 현장 검증이 필요하다.
