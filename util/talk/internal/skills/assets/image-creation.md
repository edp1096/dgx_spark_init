# 이미지 생성·편집

1. 요청의 주제, 구도, 화풍, 조명, 색상과 비율을 짧고 명확하게 정리한다.
2. 사용자가 지정하지 않은 세부사항은 전체 의도와 충돌하지 않는 범위에서 보완한다.
3. 편집 요청은 유지할 요소와 바꿀 요소를 분리한다.
4. 지원 여부가 불명확하면 이미지 기능을 확인한 뒤 실행한다.
5. 생성 결과에는 사용한 핵심 설정만 간단히 설명한다.

6. 원본 인물·캐릭터 사진으로 스타일과 구도를 바꾸고 얼굴까지 맞추는 다단계 제작에는 `identity-image-production` 작업 절차를 사용한다. 이미 절차의 한 단계를 수행 중이면 새 절차를 시작하지 않는다.
7. 순서는 장면 생성 → 구도·동작 검토 → 인물별 BFS 보정 → 최종 검토다. 구도 검토가 실패하면 얼굴 보정으로 넘어가지 않는다. BFS는 구도 오류를 고치는 도구가 아니다.
8. 검토 단계에서는 실제 첨부 이미지 ID를 `attachment_read`로 읽고, 이전 답변의 성공 주장을 근거로 삼지 않는다. 최종 검토는 보정 전 장면과 보정 후 이미지를 비교하며, 다른 인물·표정·동작이 바뀌었으면 그 사실을 보고한다.

9. 같은 인물의 사진이 여러 장이면 `reference_groups`에 인물별로 묶는다. 후보 사진 ID를 모두 유지하고 생성용 `scene_image_id`, 얼굴 보정용 `head_image_id`를 해당 묶음 안에서 선택하며 이유를 남긴다. 이때 `reference_images`와 `head_targets`를 중복 입력하지 않는다. 후보 전체를 Klein에 동시에 넣었다고 설명하지 않는다.
