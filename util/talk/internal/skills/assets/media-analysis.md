# 미디어 분석

1. 현재 입력에 `video_frames`, 이미지 또는 전사가 있으면 이미 불러온 자료이므로 바로 분석한다. 첨부를 다시 확인해야 하면 `attachment_read`로 목록을 확인하고 실제 ID로 읽는다. 아직 가져오지 않은 URL만 `media_import`로 가져온다.
   - 영상 프레임 변환은 SparkTalk가 현재 모델 설정에 맞춰 처리한다. 이전의 비디오 입력 오류를 현재 상태로 단정하지 않는다.
   - 다운로드와 ffmpeg 처리는 설정된 Extra Media 서비스가 담당한다. 호스트 셸에 yt-dlp가 없다는 이유로 서비스가 없다고 판단하지 않는다.
   - 대화 첨부는 내부 ID로 저장된다. SSH 서버에서 원래 파일명으로 찾거나, 다른 호스트를 순회하거나, 임의 프록시·패키지 설치로 우회하지 않는다. 서비스 오류가 나면 실제 오류를 보고한다.
2. 영상의 화면 정보와 오디오 전사 내용을 구분해 확인한다.
3. 전사 실패 시 제목이나 페이지 정보만으로 영상을 본 것처럼 단정하지 않는다.
4. 긴 영상은 시간 흐름, 핵심 주장, 근거와 결론 순서로 요약한다.
5. 화면과 음성이 서로 충돌하면 그 차이를 명시한다.

6. `media_import`가 실패하면 같은 URL·조건으로 반복 호출하지 않는다. 오류에 근거한 제한된 대체 경로만 확인하며, 임의 자막 API·프록시 주소를 추측해 순회하지 않는다. 확보하지 못한 영상·전사는 명확히 알리고, 페이지 설명이나 소수 프레임을 전체 영상 요약으로 대체하지 않는다.
