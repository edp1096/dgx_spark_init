# 2026-09-06 TP1 재시험

이전 재부팅으로 후보 원본이 소실되어 두 조건을 다시 측정했다.
`off`는 전체 초안 어휘, `ko64k`는 한국어를 포함하는 65,536개 초안 어휘다.
이 폴더의 두 결과 JSON은 새로 측정한 원본이며, 이전 요약에서 복원한 값이 아니다.

## 조건

- 같은 `sm121-vocab1` 이미지와 dealignai ABLITERATED NVFP4 가중치.
- 같은 난수 시드 595305611, TP1, context 65536, mem_fraction_static 0.79,
  prefill chunk 1024, MTP 3 steps / 4 draft tokens, KV dtype auto, 동시 요청 상한 2.
- 원본 컨테이너에서 CPU 배치, 메모리 제한, 볼륨을 복사한 임시 컨테이너로 순차 실행.
  원본 컨테이너와 앱의 세트 선택은 변경하지 않았다.
- 8개 프롬프트 × 3회, temperature 0, thinking off. 요청 전 prefix cache 제거.
- 도구 호출 thinking ON/OFF, 이미지, 동시 요청 2개, 35,044토큰 문맥 검색,
  JSON 3회 형식 검사. 별도로 각 조건에서 요청 없이 5분 대기 후 health 확인.
- 메모리·GPU 온도·전력·클럭·사용률을 로드부터 대기·종료까지 약 10초 간격으로 기록.
  benchmark 자체의 시스템 가용 메모리 표본은 1초 간격이다.

## 속도

각 셀은 decode tok/s 중앙값 (최소–최대)이다. MTP 스트림의 청크 수신 시각과
서버 completion token 수로 계산하며, 개별 토큰 지연 측정과는 다르다.

생성 코드의 컴파일·실행 정확성 검사는 포함하지 않는다.

## 판단과 한계

이번 3회 재시험에서는 8개 항목 모두 중앙값이 개선되어 선택 옵션으로서 실익이 있다.
다만 이전 2회 시험에서는 한국어 일부 항목이 느렸고, 이번에도 JSON 한 번은
26.90 tok/s로 떨어졌다. 반복 편차와 출력 변화가 있으므로 모든 요청에서 빨라지거나
응답 품질이 동일하다고 보장할 수 없다. 재시험의 처리량 개선과 기능 검사 통과를 근거로 ko64k를 기본 구성으로 채택했다.
필요하면 off로 이전 전체 어휘 구성으로 되돌릴 수 있다.

KV 풀은 같은 메모리 비율에서 자동 계산되어 전체 211456 / 64K 212544 토큰이었다.
따라서 결과는 실제 자동 메모리 배치 조건의 비교이며 KV 풀 크기를 고정한 미세 벤치마크는 아니다.
메모리 절약 효과를 주장하지 않는다. 추론 구간 최소 시스템 가용 메모리는
전체 21.80 GiB / 64K 21.38 GiB였다.

5분 대기 검사는 장시간 안정성을 증명하지 않으며, 이전 재부팅의 원인도 확정하지 않는다.
종료·대기 확인 결과는 complete.json 및 각 *-idle.json, 최종 요약은 summary.json에 기록한다.

## 자료

- off.json / ko64k.json: 실제 출력, 사용 토큰, 시간, 기능 검사 원본.
- *-server.json: 서버가 보고한 설정과 초기 상태.
- *-launch.json, run.json: 실행 인자, 이미지 ID, 시드, 부팅 ID.
- *-benchmark.log, *-server.log: 클라이언트와 서버 로그.
- telemetry.jsonl: 로드·추론·대기 중 시스템 표본.
- summary.json: `python3 ../../summarize.py .`로 다시 계산 가능.
