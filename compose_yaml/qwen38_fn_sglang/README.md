# Qwen Flash-Next TP2 shared recipe

The TP1 RadixArk NVFP4 recipe is archived at [zzz_not_use/qwen38_fn_radixark_nvfp4](../zzz_not_use/qwen38_fn_radixark_nvfp4/README.md). The TP2 recipe still uses the RadixArk checkpoint; its weights and TP2 cache must be retained on both Sparks. Shared build files remain here.

Use `manage_tp2.py` for the TP2 deployment. `compose.tp2.yaml` is not a TP1 recipe.

Source: the independent TP2 recipe and the archived RadixArk configuration in this repository.
