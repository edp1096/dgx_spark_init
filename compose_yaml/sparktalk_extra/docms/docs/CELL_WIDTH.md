# 셀 너비 — 0.5.2

셀 객체의 `width`를 받으며 `table.widths` 없이도 실제 PPTX 열 너비에 반영한다.
단위는 열 사이의 상대 비율이다. 같은 열의 모든 행에 적용되며, 병합 셀의
`width`는 포함된 열 너비의 합이다. 표 객체와 표 블록 모두 같은 처리를 사용한다.

```json
{"title":"비교","table":{"rows":[[{"text":"구분","width":1},{"text":"설명","width":4}],["항목","긴 설명"]]}}
```

같은 열에서 서로 다른 너비를 지정하거나 `table.widths`와 충돌하면 422와 구체적인
충돌 사유를 반환한다. 값이 일부만 주어진 경우 제약을 만족하면서 같은 너비에
가까워지도록 나머지 열을 계산한다. 양수 너비를 만들 수 없는 모호한 조합은
모든 열의 너비를 명시하도록 안내한다. 허용 범위는 0.001–1000이다.

렌더러 35개 테스트와 Talk 실제 도구 연동을 통과했다. 실행 중인 서비스에서 셀만으로
7/11/19/23/40을 지정한 결과, 실제 PPTX 열 너비는 0.84/1.32/2.28/2.76/4.80인치,
슬라이드는 1장이고 split=false였다. 병합 10 + 첫 열 3은 3.6/8.4인치로 확인했다.
PPTX 내부 XML을 검사하고 미리보기 PDF를 이미지로 확인했다.
