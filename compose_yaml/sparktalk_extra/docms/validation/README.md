# HWP / HWPX 검증

DocMS 0.4.0은 rhwp 0.8.6의 커밋 `e8800c8def63449808a4092798442652ed460552`를 고정하여 WASM을 빌드합니다. `hwp-engine/patch.py`는 표 공통 헤더를 42바이트로 보정하고, 새 문단의 합성 줄 좌표를 저장된 페이지 경계로 오인하는 문제를 수정합니다.

```sh
# DocMS 디렉터리에서 실행
./manage.sh setup
./validation/check-hancom.sh
```

생성 HWPX는 선택적인 줄 위치 캐시와 rhwp 전용 원본 스냅샷을 제거해 표준 XML을 기준으로 전체 본문을 다시 배치하도록 합니다.

검사 대상은 제목·본문·표·본문 흐름의 이미지·캡션·다음 절, 긴 표, HWP/HWPX 수정·재저장, PDF 본문, HWP 독립 파싱(pyhwp), HWPX ZIP/XML 및 파일·서식·이미지 참조입니다. 테스트 이미지는 네 가지 색으로 구성해 실제 표시 여부를 확인할 수 있습니다. 결과는 `runs/hancom/`에 저장합니다. 검증용 Python·Poppler 도구는 운영 이미지에 포함하지 않습니다.

`hwpx.mjs`, `edit-roundtrip.mjs`는 패치 전 npm 엔진을 조사했던 별도 재현 스크립트입니다. 현재 운영 엔진 검사는 위 명령으로 실행합니다.

HWPX 검사는 전체 XSD 인증이 아니며, 실제 한컴 프로그램의 열기·편집·저장은 실행 환경이 없어 미검증입니다. PDF는 동일 내용으로 별도 조판하므로 원본과 줄바꿈·페이지 배치가 다를 수 있습니다.
